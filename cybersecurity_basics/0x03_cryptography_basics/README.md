# 🔐 Cryptography Basics

Welcome to the **Cryptography Basics** repository. This project is a foundational exploration of cryptographic principles, tools, and techniques used in modern cybersecurity. It covers everything from basic encryption concepts to advanced hash-cracking using industry-standard tools on **Kali Linux**.


---

## 📖 Project Description

Cryptography is the backbone of digital security. This project focuses on understanding how sensitive data is protected through encryption, how identities are verified through hashing, and how security professionals test the strength of these protections using password-cracking utilities.

The scripts included in this repository are designed to automate cryptographic tasks, following strict shell scripting requirements and the **Betty coding style**.

---

## 🎯 Learning Objectives

By the end of this project, the following concepts are mastered:

### Fundamentals

* **What is Cryptography?** Understanding its role in securing information within the cyber landscape.
* **Encryption vs. Decryption:** The process of converting plaintext to ciphertext and vice versa.
* **Hash Algorithms:** Understanding one-way functions and what **SHA** (Secure Hash Algorithm) stands for.
* **Applications:** Recognizing cryptography in daily life (HTTPS, VPNs, Secure Messaging).

### Tooling & Practical Skills

* **John the Ripper:** Mastering hash format identification and cracking.
* **Hashcat:** Utilizing GPU/CPU power to crack advanced hashes.
* **OpenSSL:** Using the toolkit for various cryptographic operations.

---

## 🛠 Requirements & Constraints

To ensure code quality and system compatibility, all scripts adhere to these strict rules:

* **Platform:** Tested on **Kali Linux**.
* **Script Length:** Exactly **2 lines** per script.
* **Header:** Every script starts with `#!/bin/bash`.
* **Coding Style:** Follows the **Betty style** (checked via `betty-style.pl`).
* **Executable:** All files are granted execution permissions.
* **Syntax Constraints:** No backticks (```), `&&`, `||`, or `;` allowed.
* **Naming Convention:** All cryptographic algorithms (e.g., `sha256`) are written in **lowercase**.
