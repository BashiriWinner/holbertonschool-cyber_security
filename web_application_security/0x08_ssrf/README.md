
# 🌐 Server-Side Request Forgery (SSRF)

---

## 📝 Description

Welcome to the **Server-Side Request Forgery (SSRF)** project! 

This project explores the mechanics, impact, and mitigation of SSRF vulnerabilities. Server-Side Request Forgery is a web security vulnerability that allows an attacker to induce the server-side application to make HTTP requests to an arbitrary domain of the attacker's choosing. 

Throughout this project, you will learn how to identify, exploit, and patch SSRF vulnerabilities. Your primary target for the practical applications in this repository will be **Cyber - WebSec 0x08**. 

---

## 🎯 Learning Objectives

By the end of this project, you are expected to be able to explain the following concepts clearly to anyone, **without the help of Google**:

* What is SSRF?
* How does SSRF work under the hood?
* What is an SSRF attack and how is it executed?
* What are the different types of SSRF attacks (e.g., Basic, Blind)?
* What is the impact of successful SSRF attacks?
* What are the specific risks associated with SSRF?
* What are some common SSRF attack scenarios in real-world applications?
* How can you protect systems against SSRF attacks?
* How do you prevent SSRF attacks at the architectural level?
