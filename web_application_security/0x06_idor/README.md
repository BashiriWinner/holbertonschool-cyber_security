
# Insecure Direct Object Reference (IDOR)



## 📌 Project Overview
This project focuses on identifying, exploiting, and mitigating **Insecure Direct Object Reference (IDOR)** vulnerabilities. IDOR is a critical access control flaw (often featured in the OWASP Top 10) that occurs when an application provides direct access to objects based on user-supplied input. This repository contains one-line scripts and documentation designed to test for and understand IDOR against the specific target environment.

---

## 🎯 Target Environment
* **Designated Target:** `Cyber - WebSec 0x06`

---

## 🧠 Learning Objectives
By the end of this project, you will be able to explain the following concepts without external assistance:

* **Core Concepts:** What an IDOR is and the exact meaning of "insecure direct object reference."
* **Mechanics:** How IDOR works and how an IDOR attack practically happens.
* **Comparison:** The difference between IDOR and other web application vulnerabilities.
* **Scope & Impact:** The various types of IDOR vulnerabilities and their potential impact on a system.
* **Defense & Auditing:** How to detect IDOR vulnerabilities, prevent attacks, and apply IDOR mitigation best practices.
