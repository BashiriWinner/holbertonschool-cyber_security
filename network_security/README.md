# 🌐 Networking Foundations & Architecture



## 📖 Description

**Welcome!** You’re about to embark on a journey that will transform how you understand **networks** and **security**. Every cybersecurity professional needs this knowledge—it is the foundation of everything we do.

This project covers the essential building blocks of the internet, from how computers connect physically to how data is routed across the globe, and ultimately, how to secure those connections against modern threats.

## 🗂️ Concepts Overview

This repository focuses on the following core pillars of networking:

* Network Basics & Reference Models
* Network Communication and Addressing
* Networking Commands & Ports Cheatsheets
* Network Services (DNS, DHCP, etc.)
* Internet Architecture & Wireless Networks
* Network Security & Defense Strategies

## 🎯 Learning Objectives

By the end of this project, you will be able to explain the following concepts clearly and without external aid.

### 1. Network Basics & Reference Models

Understanding the theoretical maps of the internet.

* **Fundamentals:** What is networking? Diff between LAN vs. WAN.
* **Topologies:** The main network shapes (Bus, Star, Ring, Mesh) and physical vs. logical topology.
* **The OSI Model:**
* The 7 layers and their specific functions.
* What happens at each layer during data transmission?
* **Encapsulation & Decapsulation:** How data is wrapped and unwrapped.


* **The TCP/IP Model:**
* The 4 layers and how they compare to OSI.



### 2. Physical & Data Link Layers (L1/L2)

Hardware, switching, and local addressing.

* **Devices:** The roles of a Hub, Switch, Router, and Firewall.
* **Layer Differentiation:** Difference between Layer 2 (Data Link) and Layer 3 (Network) devices.
* **MAC Addresses:**
* Structure (OUI vs. NIC-specific).
* Special addresses (Broadcast, Multicast).


* **VLANs (Virtual LANs):**
* Why use them? What is **802.1Q tagging**?
* **Inter-VLAN routing:** How to route between them.
* **Attacks:** VLAN hopping and prevention.



### 3. IP Addressing & Subnetting (L3)

The language of routing.

* **IPv4:** Format, Classes (A, B, C, D, E), and Private IP ranges (RFC 1918).
* **Special IPs:** Loopback (127.0.0.1) and Broadcast.
* **Subnetting:**
* Understanding **CIDR notation**.
* Calculating subnets, hosts per subnet, and network ranges manually.


* **ARP (Address Resolution Protocol):** How it maps IP to MAC, and the dangers of ARP Spoofing.
* **IPv6:** Why it was developed and how it differs from IPv4.

### 4. Transport & Application Protocols

How data moves and how applications talk.

* **Protocols:** HTTP, HTTPS, FTP, SSH, DNS, DHCP.
* **TCP vs. UDP:** Reliable vs. Fast transmission.
* **Ports:**
* Well-known (0-1023), Registered, and Dynamic ports.
* The difference between "Open", "Closed", and "Filtered" states.



### 5. Critical Network Services

The infrastructure that makes the network usable.

* **DHCP (Dynamic Host Configuration Protocol):**
* The **DORA process** (Discover, Offer, Request, Acknowledge).
* Leases, renewals, and security (Rogue Servers, Starvation attacks, Snooping).


* **NAT (Network Address Translation):**
* Static vs. Dynamic vs. PAT (Port Address Translation).
* Port Forwarding and NAT Traversal (STUN, TURN).


* **DNS (Domain Name System):**
* Hierarchy (Root, TLD, Authoritative) and Resolution process.
* Records: A, AAAA, CNAME, MX, NS, TXT, PTR.
* **Security:** DNS Spoofing, Tunneling, DNSSEC, and DoH/DoT.



### 6. Authentication & Directory Services

Identity management in a network.

* **AAA:** Authentication, Authorization, Accounting.
* **Protocols:**
* **RADIUS vs. TACACS+:** Differences in function and security.
* **Kerberos:** How it works and attacks targeting it.
* **LDAP:** Usage in directory services.
* **802.1X:** Network Access Control (NAC) and EAP methods.



### 7. Internet Architecture & Wireless

Global routing and radio waves.

* **Global Routing:**
* Autonomous Systems (AS) and ASN.
* **BGP (Border Gateway Protocol):** Peering vs. Transit, and BGP Hijacking.
* IXPs (Internet Exchange Points) and CDNs (Content Delivery Networks).


* **Wireless (Wi-Fi):**
* Frequencies (2.4, 5, 6 GHz) and Standards (802.11a/b/g/n/ac/ax).
* **Security:** WEP vs. WPA/2/3. PSK vs. Enterprise.
* **Attacks:** Evil Twin, Deauth, KRACK.



### 8. Network Security & Defense

Protecting the infrastructure.

* **Core Principles:**
* **CIA Triad:** Confidentiality, Integrity, Availability.
* Defense in Depth, Least Privilege, Zero Trust.


* **Firewalls:** Packet Filtering, Stateful, NGFW, and DMZ configuration.
* **Monitoring:**
* **IDS vs. IPS:** Detection vs. Prevention.
* **SIEM:** Logging and analysis.
* **Syslog:** Severity levels.


* **Attacks:**
* **DoS/DDoS:** Volumetric, Protocol, Application.
* **MitM:** Man-in-the-Middle attacks.
* **Reconnaissance:** Scanning and Enumeration (SNMP, NetBIOS).
