
# 🛡️ Project: Buffer Overflow


---

## 📝 Description

This project dives into the fundamentals of **Memory Corruption** and **Cybersecurity**, specifically focusing on one of the most classic and notorious vulnerabilities: the **Buffer Overflow**. 

Throughout this project, we will explore the architecture of memory, understand how buffers work, and learn exactly how attackers exploit these boundaries to inject malicious code. More importantly, we will cover the mitigation strategies and safe coding practices required to prevent these attacks in modern software development.


---

## 🎯 Learning Objectives

By the end of this project, you should be able to explain the following concepts to anyone, entirely without the help of Google:

* **Basic Concepts:** What is a buffer, and what is a Buffer Overflow?
* **The Attack:** What is a Buffer Overflow Attack, and what causes them?
* **Mechanics:** How do attackers orchestrate Buffer Overflow Attacks?
* **Variations:** What are the different types of buffer overflow attacks?
* **Detection & Impact:** How can you detect a buffer overflow, and what are its consequences?
* **Defense:** How do we prevent and mitigate Buffer Overflow Attacks?

### Python Scripts
* **Allowed Editors:** `vi`, `vim`, `emacs`
* **Environment:** All files will be interpreted/compiled on Ubuntu 14.04 LTS using `python3` (version 3.4.3).
* **Formatting:**
  * All files should end with a new line.
  * The first line of all your files must be exactly: `#!/usr/bin/python3`

* **Execution:** All your files must be executable.
* **Testing:** The length of your files will be tested using the `wc` command.
* **Documentation:** A `README.md` file at the root of the project folder is mandatory.

* All files should end with a new line.
